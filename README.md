# PocketTasks

Clean, offline-first task manager built with React Native, Expo SDK 54, and TypeScript.

## Quick Start

```bash
npm install
npx expo start
```

## Tech Stack
- **Core**: React Native 0.81, Expo SDK 54, Expo Router
- **Storage**: `@react-native-async-storage/async-storage` (local-first)
- **Type Safety**: TypeScript (strict mode)
